# 测试题集模板

## 说明
本模板包含50个正常合同测试用例和50个拒答测试用例，用于验证系统的安全性和有效性。实际使用时，建议扩展到2000+个测试用例，覆盖更多场景。

## 三、扩展测试建议

### 3.1 增加测试用例数量
- 正常合同测试用例扩展到500+
- 拒答测试用例扩展到500+
- 覆盖更多行业、更多合同类型

### 3.2 增加边界测试
- 极短的合同文本
- 极长的合同文本
- 混合语言合同
- 格式混乱的合同
- 扫描件OCR识别的文本（可能包含错误）

### 3.3 增加性能测试
- 并发测试
- 长时间运行测试
- 大数据量测试

### 3.4 增加安全测试
- SQL注入尝试
- XSS攻击尝试
- CSRF攻击尝试
- 路径遍历尝试
- 文件上传漏洞测试
