# 合同审查第二版语义升级计划（房屋租赁原型）

## Summary

将房屋租赁合同审查第二版从“关键词/短语匹配”升级为“条款切分 + 语义判定 + 原文证据定位”的规则版语义审查原型。审查报告只输出风险提示、修改建议、法律依据和证据原文，不输出任何裁判结论。

## Key Changes

- 新增条款解析层，将上传合同切分为 `使用说明 / 特别提示 / 正式合同条款 / 附件`，审查时默认只把正式合同条款和附件作为有效证据。
- 保留房屋租赁 50 条 `ReviewCheckpoint`，并为每条检查点补充语义问题、证据范围、通过标准和部分覆盖标准。
- 核心流程调整为：候选条款召回 → 规则版语义判定 → 证据化报告生成。
- API 返回新增 `coverage_status`、`evidence_clauses`、`evidence_location`、`reasoning_summary`。
- 前端报告展示命中原文、系统判断理由、覆盖状态筛选，并继续支持 `待处理 / 已处理 / 忽略` 和律师备注。
- PDF 导出同步包含原文证据、判断理由、人工复核状态和备注。

## Implementation Notes

- 条款解析器位于 `backend/review_v2/clause_parser.py`。
- 规则版语义判定器位于 `backend/review_v2/semantic_reviewer.py`。
- `terms` 只作为候选条款召回信号，不再直接决定最终风险结论。
- 空白项检测覆盖 `____`、连续空格、未勾选 `□`、空白金额、空白日期等常见示范文本形态。
- 当前阶段仅启用房屋租赁合同原型，其余合同类型仍保持前端禁用状态。

## Test Plan

- 验证条款切分能识别示范文本的使用说明、特别提示、正式条款和附件。
- 验证 50 条房屋租赁审查点完整加载。
- 验证“押金不计息”“不得变更租赁用途”不会导致押金、用途类误判。
- 验证空白金额、空白日期、未勾选选项会被识别为“部分覆盖”或“缺失”。
- 使用 `test_data/《城镇房屋租赁合同（示范文本）》（GF—2025—2614）.docx` 跑完整审查，确认报告包含 50 项、原文证据、条款位置和判断理由。
- 验证报告和 PDF 不包含 `判决结果 / 裁判结论 / 驳回请求 / 应赔偿` 等裁判式表述。

## Assumptions

- 本阶段不接入云端模型，先实现本地规则版语义审查，保留后续模型判定接口。
- 审查报告不保存合同原文到数据库。
- 人工复核状态和备注先保存在前端当前报告状态，并随 PDF 导出。
