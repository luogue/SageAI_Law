# 算法安全自评估报告

## 一、算法概述

### 1.1 算法名称
SageAI 合同审查算法

### 1.2 算法功能
本算法用于审查合同文本，识别潜在法律风险，提供分析报告。

### 1.3 技术实现
- 模型：DeepSeek大语言模型
- 框架：FastAPI 后端
- 核心流程：合同文本 → 风险识别 → 生成分析报告

### 1.4 应用场景
- 企业合同合规审查
- 法律专业人士辅助分析
- 合同文本风险评估

---

## 二、数据处理

### 2.1 输入数据
- **数据类型**：合同文本（Word/PDF/纯文本）
- **数据来源**：用户上传
- **数据量**：单份合同通常1000-10000字符

### 2.2 数据处理流程
1. 用户上传合同文件
2. 系统临时读取合同内容到内存
3. 进行内容分析和风险识别
4. 生成审查报告
5. 分析完成后立即丢弃原始合同内容

### 2.3 数据存储策略
- **不保存原始合同**：合同文本仅在内存中临时处理，审查完成后立即丢弃
- **保存内容**：仅保存审查报告、文件名、用户标识、操作时间
- **用户数据保护**：采用密码哈希存储用户密码，日志脱敏处理

### 2.4 数据安全措施
- 敏感词本地过滤（AC自动机）
- 可选阿里云内容安全API接入
- 用户限流和黑名单机制
- 日志敏感信息自动脱敏

## 四、风险控制

### 4.1 模型输出风险
- **风险类型**：模型可能输出不准确或误导性信息
- **缓解措施**：
  - 系统提示词强制输出审查流程和风险说明
  - 向用户明确声明：AI分析仅供参考，不构成正式法律意见
  - 建议咨询执业律师

### 4.2 提示词注入风险
- **风险类型**：用户可能通过合同或额外要求尝试获取系统提示词或绕过限制
- **缓解措施**：
  - 在系统提示词中添加安全指令，禁止输出系统信息
  - 敏感词过滤检测可疑输入
  - 日志审计异常行为

### 4.3 滥用风险
- **风险类型**：用户可能滥用服务进行违规活动
- **缓解措施**：
  - 基于用户ID和IP的双重限流
  - 黑名单管理机制
  - 安全事件日志记录

### 4.4 数据泄露风险
- **风险类型**：合同内容可能通过日志或存储泄露
- **缓解措施**：
  - 不保存原始合同文本到磁盘或数据库
  - 日志自动脱敏处理
  - 定期审计日志
