# 相邻规则层检查

- 抵押与动产、股权、权利质押：共用 security_property_checklist 的 SEC 要素。本轮分类在共享规则注册处声明，因此同步区分合同清偿后协助义务、法定实现/清算规则及登记资料核验。抵押行权与质权行权分别引用第419条和第437条，不将抵押诉讼时效机械套用于质押。
- 租赁：保留现有法定补位机制与合同 coverage 分离，不将一般法律依据自动转换为 statutory default；本轮未迁移或修改租赁语义检索配置。HL-009/013/020/039 的正向及 HL-035/037/040/041/042 的负向回归继续执行。
- 买卖：domain_packs 中已有检验合理期限、质量救济等法律补位；不将具体检验时长、操作程序和证据要求自动视为已补足。本轮未将这些不同目标要素整体改为法定默认规则。
- 保证：现有 guarantee_mode 已将特定法定事项作为法律提示。另发现 GUA-05-01 保证期间明确仍登记为高风险 required，GUA-01-04 公司授权基础仍混有提交文件与实际决议核验表述；应按真实交易角色和法定期间剩余风险进一步核对，不能仅凭条文存在直接降级。本轮记录为后续候选，未声称全部保证规则已迁移到三类要素模型。

本轮三类要素模型对使用 required 注册器的规则通用生效；其他专用规则引擎保留现有路径。法定补位须显式登记直接法律命题，不能由 legal_basis 非空推导。
