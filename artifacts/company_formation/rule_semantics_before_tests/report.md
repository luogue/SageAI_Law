## 二、核心风险摘要

- **筹备临时账户与出资资金安全**：优先处理。仍需补足：支出共同审批及监督、个人财产隔离及禁止挪用、转入公司账户的期限及核对、设立失败的退款及费用结算。 建议：建议补充明确支出共同审批及监督；补充明确个人财产隔离及禁止挪用；补充明确转入公司账户的期限及核对；补充明确设立失败的退款及费用结算。

- **股权转让、优先购买、退股及资本维持**：优先处理。发现与本项法定保护相冲突的直接不利约定。股权对外转让机制仍采用旧式过半数同意安排，未明确章程特别约定依据；需结合现行公司法第84条的书面通知、同等条件优先购买及公司章程核对并更新，不直接认定该约定无效。 建议：建议调整以下已确认的不利安排：股权转让、优先购买、退股及资本维持存在直接不利约定。

- **重大事项单方决定权冲突；股东知情权受单方审批限制**：优先处理。单方否决或决定权覆盖重大经营事项，需与共同表决及法定保留事项协调；存在股东会不消除该控制权限制。；股东查账以另一股东同意为前提，属于知情权限制，不能作为充分保障知情权的正向证据。 建议：建议删除或限制重大事项的单方最终决定及跳过协商授权，明确合法表决与僵局解决机制；区分查阅不同财务材料的法定程序，不以另一股东自行同意作为统一查阅前提，保留法定监督和救济渠道。

- **认缴期限法定上限及成立日核验**：优先处理。已约定出资缴付期限，但按正文的成立/拟设时间，该截止时间超过成立起五年的原则上限；应核对登记成立日及法律、行政法规或国务院决定的特殊规定并调整。拟设年份据合作/营业安排推定，不将合作起日或签署日当作已登记成立日。 建议：建议保留已经约定的缴付日期，核对公司成立日及法定特别规定；原则上将认缴期限限制在成立起五年内，不能把明确日期等同于合法。

- **出资方式、股权比例、认缴实缴及期限**：建议处理。仍需补足：未按期出资的补足及违约责任。 建议：建议补充明确未按期出资的补足及违约责任。

- **非货币及技术出资合法性、权属、估值和交付**：建议处理。仍需补足：出资财产可估价且依法可转让、资产权属及权利负担核验、评估作价依据及估值不足补足、资产交付及财产权移转至公司。 建议：建议补充明确出资财产可估价且依法可转让；补充明确资产权属及权利负担核验；补充明确评估作价依据及估值不足补足；补充明确资产交付及财产权移转至公司。

- **设立股东、公司主体及注册资本**：建议处理。发现与本项法定保护相冲突的直接不利约定。同一股权结构持股比例合计为110%，不等于100%。；各股东认缴合计110万元，与注册资本100万元不一致。；戊方出现在股权结构中，但未识别其签约身份或签署，需补充主体加入及认缴安排。；合作期限终止日2034-09-30超过基础租赁期限终止日2031-06-30，与不得超出基础租赁期限的约定冲突。 建议：建议调整以下已确认的不利安排：设立股东、公司主体及注册资本存在直接不利约定。

- **利润分配、亏损承担及经营资金留存**：建议处理。发现与本项法定保护相冲突的直接不利约定。按利润提取股东费用并允许自行支配或免交支出凭证，存在关联利益输送与费用真实性、资金监督风险。 建议：建议调整以下已确认的不利安排：利润分配、亏损承担及经营资金留存存在直接不利约定。

- **公司章程与股东协议衔接**：建议处理。仍需补足：治理与出资约定同步载入章程。 建议：建议补充明确治理与出资约定同步载入章程。

- **一般违约责任及损失赔偿**：建议处理。发现与本项法定保护相冲突的直接不利约定。一方责任被限定为有书面证据的直接实际损失，应与其他方违约金及继续赔偿责任比较，核对责任分配与救济限制。 建议：建议调整以下已确认的不利安排：一般违约责任及损失赔偿存在直接不利约定。

- **法律引用建议更新**：建议处理。合同订立依据仍引用已废止法律，属于法律依据引用过时问题。 建议：建议将《中华人民共和国合同法》更新为《中华人民共和国民法典》相应规定。
