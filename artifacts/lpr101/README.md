## 根因与实现

- loan_costs.py 原先将两条规则纳入同一个 COST_NODES，并注入必需的 loan_cost_combined_limit；无兜底条款就变为缺失。
- 原先跨基数、跨期间直接合计年化百分比。现在每个收费保留 base、scope、amount_formula；不完整的可并行关系保留为待核验，不当作已证实超限。
- lpr_protection.py 将合同公式覆盖与司法保护核验分开，按成立日期查带有效区间和出处的参考数据；未来或未收录日期不沿用最新数据。
- 本地参考数据 lpr_reference.json 目前收录央行已核验的2025年5月20日至7月20日区间；其他未收录时期保持待核验，可通过 LPR_REFERENCE_FILE 指向新增的经核验数据。不会把合同自行声明的LPR当官方验证。
- 以未付利息为基数的违约金保留符号公式；只有提供同一计息窗口的实际本金/未付利息数据时才按比例换算。当前未来合同没有据此声称金额合规或违法。
- L-05-02 独立核验逾期标准、基数及起止期，不消费 LPR 上限风险结果。
- 质量门校验外部PENDING不得变成合同缺失或已核验合法；已证明公式的证据不会被外部核验状态清空。
