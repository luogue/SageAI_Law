# 房屋租赁复合要素证据复测

发布继续阻断：`release_quality_gate=BLOCKED`。未解除房屋租赁类型的复测限制。

## 修改与根因

1. `backend/review_v2/lease_semantics.py`
   - 不可抗力原规则将“不能履行”误当作处理机制、将“通知解除”误当作事件通知和证明。现在分别要求实际处理机制、事件通知及证明事实，禁止同主题关键词交叉代替。
   - 新增声明式 `required_fact_patterns`，各必要事实组必须全部命中；提前退出的条件和后果在同一边界明确的条款内核验。仅有通知不能证明完整复合要素；违约金、赔偿、明确免责或退出结算均可以按各自真实内容证明后果。
   - 区分“存在提前退出约定”和“退出条件及后果完整”。前者供适用性判断使用，避免不完整条款被误判为完全没有提前退出约定。
   - 删除经济暴露证据对完整法律事实证据的替换，coverage 与 SEARCH_AUDIT 使用同一个复合要素判定机制。
   - 原始证据抽取时保留完整 quote；规则包统一 text / quote / quoted_text。仅在截取后的文本仍足以证明全部必要事实时才缩短展示，防止完整 text 与旧截短 quote 并存。
2. `backend/tests/test_lease_composite_evidence.py`
   - 新增 7 项专项用例：不可抗力映射正反例、仅有条件不能 PASS、具备条件及后果才能支持复合要素、其他条款违约金不得补足当前退出要素、原始及展示证据均能解释 coverage。
3. `scripts/run_lease_scenario_acceptance.py`
   - 支持独立输出目录；增加目标要素与展示证据一致性、通知及违约后果完整展示断言。沿用同一合同两次真实 multipart 路由复测，比较 coverage、规则证据包和风险汇总。

没有按 HL 编号或当前合同结果硬编码生产判定。
