# 附随服务费用：独立迁移依据

原 fixture `26 技术转让（技术秘密）合同.docx` 未修改。
第十条：“乙方累计提供现场技术服务不超过10个工作日。超过10个工作日的服务，由双方另行协商收费。”
第十一条：“本合同固定技术转让费总额为人民币3,000,000元。”其后为转让费三期付款。

前者直接证明约定服务量以及额外收费触发条件，但没有“包含在转让费”“不另行收费”或明确将服务费接入三期付款的表达。
旧断言把该语义推断为两项全部覆盖，证据不足。
迁移：service_fee_amount COVERED → PARTIALLY_COVERED（保留工作量/超额收费直接证据）；service_payment_schedule COVERED → MISSING（没有服务费付款关系）。
整体仍 PARTIAL，额外收费标准、工作量确认、付款节点三个缺口不变。
此项属于实现修正兼旧断言迁移，不计入纯实现恢复。新增对照测试分别验证明确总价包含、明示另行收费、仅有服务义务，防止以当前结果倒推预期。

关联来源断言同步迁移（不计业务恢复）：`test_service_fee_and_confidentiality_use_only_direct_operational_clauses` 原要求C0012转让费分期付款也必须成为服务费正向证据。既然没有价款关联，恢复该引文反而违反“每条引文直接支持要素”的契约。改为仅C0011服务量和超额收费原文，SEARCH_AUDIT单独按负向证据处理；保密来源的全部断言不变。
